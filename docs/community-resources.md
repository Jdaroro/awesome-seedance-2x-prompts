# Community Resources

This page indexes useful third-party and community projects related to AI video prompting, cinematic planning, and Seedance workflows.

These projects are independent of this repository. Inclusion here is for reference only and does not imply endorsement, compatibility guarantees, or redistribution rights.

## Framewright

- Repository: https://github.com/jamesltr0701-cell/Framewright
- Type: community cinematic compiler / AI filmmaking pre-production toolkit
- Scope: storyboard, keyframes, video-prompt compilation, reference handling, continuity, camera/motion, lighting/sound, and target-model runtime adapters
- Target-model support documented upstream includes Seedance 2.0, Seedance 2.5, and MiniMax H3.

Framewright is useful as an architectural and workflow reference for people studying how a larger AI filmmaking system can separate director intent, production state, reference authority, and target-model serialization.

For current behavior, versions, licenses, installation instructions, and model-specific details, always consult the upstream repository directly.

## Contribution guidance

Community resources added here should be:

- publicly accessible;
- materially relevant to Seedance, AI-video prompting, or production workflows;
- described without copying large portions of upstream documentation;
- clearly identified as third-party material;
- linked to the original source whenever possible.
